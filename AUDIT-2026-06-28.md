## Performance

Routes lazy-split; Leaflet (~152 KB) loads only when the Route tab opens. Summer hub chunk
~36 KB (9 KB gz). Photo-book ~13 KB. Animations are pure CSS keyframes (GPU transform/opacity)
and all respect `prefers-reduced-motion`. SW precaches the shell; storage photos cached for
offline. Query cache hydrates from localStorage for instant cold boots.

## Residual / known limitations (honest)

- Camera grant-once, the share sheet, and Wall pinch-resize/drag/haptics are now
  **functionally proven** (see device-behavior tests). What remains genuinely
  unobservable from here: the literal **push buzz on the physical lock screen** (the
  system is proven ready — registered devices + ACTIVE function) and the **subjective
  taste/feel** of the animations. Both need a human holding the phone — not a code gap.
- **Currency rates** are a static seed/snapshot; no cron refreshes them (re-run the
  `currency-rates` edge fn to update — pre-existing limitation, unchanged).
- `database.types.ts` is generated via `supabase gen types --project-id` (Management API);
  `--local` needs Docker, which is unavailable in this environment.

## Rollback

Each change is a single-file commit on `main` (force-push allowed). The DB migrations are
additive and idempotent; the only data mutation is the special-trip rename + GE backfill +
leg seed (reversible by hand if ever needed).
